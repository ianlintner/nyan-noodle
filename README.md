# Nyan Noodle

A free-to-play browser cat ramen shop management game: pixel art with voxel-style shading, a cozy Cook/Serve daily loop, and incremental shop growth (Cart -> Stall -> Small Shop and beyond).

Status: planning. No app code yet; see [PLAN.md](PLAN.md) for the stack, art direction, MVP scope and card breakdown.

Stack (planned): Phaser 4 + TypeScript + Vite, pure-TS deterministic sim package, Vitest, Playwright, static hosting on Azure Static Web Apps.
